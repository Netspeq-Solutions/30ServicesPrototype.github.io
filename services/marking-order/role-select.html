Select Your Access Role

Welcome to the Marking Order Service prototype demonstration. Select any of the six supported roles below to evaluate its dedicated dashboard, role-specific navigation menu, statutory authority rules, and demonstration application records.

Prototype Demonstration Note: Actual authentication through Sikkim GO (SSO) is not required for this prototype. All user accounts shown below are prototype demonstration users. You can switch between all six roles and jurisdictions at any time without restarting.
Option 1 Citizen Applicant

Citizen

Access the Marking Order service to apply for a tree felling Marking Order, manage applications submitted on your own behalf or on behalf of another citizen, and track application progress.

Option 2 Forest Range Desk

Range Officer (RO)

Access range-wise applications, perform preliminary scrutiny, schedule field verification, assign Block Officers and review submitted verification reports.

Statutory Limit: Firewood ≤ 3 | Timber ≤ 3
Option 3 Field Verification

Block Officer (BO)

Access assigned field verification applications, verify land and tree details, capture site photographs and GPS information, and submit verification reports to the Range Officer.

Rule: Verification only; cannot reject applications
Option 4 Sub-Divisional Authority

Assistant Conservator of Forests (ACF)

Access applications forwarded by Range Officers, review verification reports, process applications within statutory authority and forward applications requiring DFO approval.

Statutory Limit: Firewood ≤ 6 | Timber ≤ 6
Option 5 Final Division Authority

Divisional Forest Officer (DFO)

Access division-level applications, review escalated cases, monitor delayed applications, manage issued Marking Orders and access division-wide reports.

Final Authority: Firewood ≤ 10 | Timber ≤ 10
Option 6 System Administration

Super Admin

Access overall system administration, user management, master configuration and system-level monitoring.

Active User: Super Admin Demo User
Statewide access across all 6 Districts, Divisions, Forest Ranges, Tree Species & Purpose Masters
